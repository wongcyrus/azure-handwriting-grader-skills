Banner artwork and brand provenance

All eight banners reuse the previously approved editorial artwork. The original 1536 x 1024 image was generated once with Azure OpenAI for the earlier prototype (one request, estimated US$0.00713). This update makes no new image requests. editorial-art.jpg is a metadata-free publication derivative; the original PNG, prompt and private billing journals remain outside this publication package. The 2400 x 1260 layout masters upscale the artwork; they do not contain newly generated higher-resolution detail.

The four brand assets are composited locally, not generated or redrawn by AI. Full aspect ratios and colors are preserved, with separate whitespace and nearby product labels. The MVP badge denotes the author's affiliation; the other marks identify technologies discussed, not application branding or Microsoft endorsement.
